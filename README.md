# A/B-тест новой формы оплаты ЖКХ

## О проекте
Команда платежей запустила A/B-тест новой упрощённой формы оплаты ЖКХ. Тест шёл 30 дней (1–30 апреля 2024).

Клиентов разделили на две группы:
- **A** — старая форма
- **B** — новая упрощённая форма

Оплата проходит в 4 шага:
1. Открыл форму
2. Ввёл реквизиты
3. Подтвердил платёж
4. Успешная оплата

**Ключевая метрика** — конверсия из шага 1 в шаг 4.  
**Гипотеза:** новая форма увеличит долю успешных оплат.  
**Цель:** понять, стоит ли раскатывать новую форму на всех пользователей.

## Стек
- Python, Pandas
- Matplotlib
- statsmodels (Z-тест для пропорций)

## Что сделано
1. Загрузка и проверка качества данных (пропуски, аномальные значения возраста).
2. Проверка корректности сплита.
3. Построение воронки оплаты и сравнение групп.
4. Статистическая проверка гипотезы (Z-тест).
5. Визуализация результатов.
6. Формулировка рекомендации.

## Главные выводы
- Конверсия из шага 1 в шаг 4:
  - Группа A (старая форма): **49,7%**
  - Группа B (новая форма): **64,4%**
- Абсолютный прирост: **+14,7 п.п.**
- Z-тест показал статистически значимую разницу (p-value << 0.05).
- Новая форма улучшила конверсию на каждом шаге воронки.

## Рекомендация
**Запускать новую форму оплаты на всех пользователей.**  
Она статистически значимо увеличивает долю успешных оплат.

Ограничения:
- Стоит отдельно посмотреть количество обращений в поддержку после внедрения.
- Продолжить мониторинг конверсии после раскатки.
